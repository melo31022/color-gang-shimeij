## Alan Becker's Stickfigures Unofficial

Reference project: https://github.com/Skittlq/alan-beckers-stickfigures-unofficial

The reference repository identifies itself as an unofficial application based on Kilkakon's Shimeji-ee. Its root LICENSE file contains the MIT License and credits kirillocha (2024). Its README separately credits Stickwave/@StickLaserPhase for character animations, behaviors, actions and sprites.

This Python project is an independent reimplementation of desktop-pet behavior. It does not include the reference project's Java bytecode, JAR files, installer, or third-party character sprites. The only character images loaded by this application are the PNG files already present in this repository.
