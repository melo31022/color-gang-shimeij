## Alan Becker's Stickfigures (Unofficial)

Source: https://github.com/Skittlq/alan-beckers-stickfigures-unofficial

Pinned source commit: 6e32aeb3956912c1d7d8396d885cb2b61be63193

The upstream README states that the application is an unofficial customized standalone app based on Kilkakon's Shimeji-ee. It credits Stickwave / @StickLaserPhase for the character animations, behaviors, actions and sprites.

This project downloads the original character PNG files and per-character Shimeji XML animation definitions from the source repository on first launch. Only img/<character>/*.png and the corresponding conf/actions.xml and conf/behaviors.xml are extracted. Java source, compiled classes, JARs, installers and the original Java runtime are not used.

The upstream repository's MIT license is included in UPSTREAM_LICENSE.txt. The original README's creator credits are retained here. The sprites and animations remain third-party assets; this Python application is an independent implementation and is not endorsed by or affiliated with Alan Becker, Skittlq, Kilkakon or Stickwave.
